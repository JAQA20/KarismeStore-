Guía de Instalación Local

Instrucciones paso a paso para configurar y ejecutar el proyecto La Comanda SaaS en máquinas Windows desde cero.

info

Antes de empezar

Para ejecutar este proyecto no necesitas instalar Node.js, PHP ni MySQL directamente en tu computadora. Todo el proyecto (Frontend, Backend y Base de Datos) funciona de manera encapsulada usando Docker. Si sigues esta guía al pie de la letra, evitarás cualquier problema de "en mi máquina no funciona".

1 Instalación de WSL2 (Requisito de Windows)

Docker necesita WSL2 (Windows Subsystem for Linux) para funcionar de manera rápida y óptima en Windows.

  1. Abre PowerShell como Administrador: Presiona la tecla Windows, escribe "PowerShell", haz clic derecho y selecciona "Ejecutar como administrador".
  2. Ejecuta el comando de instalación: Copia y pega el siguiente comando en la ventana azul y presiona Enter:
    wsl --install
  3. Reinicia tu computadora: Este paso es obligatorio. Una vez reinicies, es posible que aparezca una terminal negra configurando Ubuntu; puedes cerrarla cuando termine.

2 Instalar Docker Desktop

Docker es el motor que ejecutará toda nuestra aplicación.

  1. Ve a la página oficial y descarga Docker Desktop para Windows.
  2. Ejecuta el instalador. Asegúrate de que la casilla "Use WSL 2 instead of Hyper-V" (Usar WSL 2 en lugar de Hyper-V) esté marcada durante la instalación.
  3. Abre la aplicación Docker Desktop desde tu menú inicio. Acepta los términos si te los pide. Sabrás que está listo cuando veas un ícono de una ballena verde (o la palabra "Engine Running") en la esquina inferior izquierda de la aplicación.

3 Descargar el Proyecto

Necesitamos traer el código fuente a tu máquina. Si no tienes Git instalado, descárgalo aquí.

  1. Abre una terminal (PowerShell o Git Bash) en la carpeta donde guardas tus proyectos (ej: Documentos).
  2. Clona el repositorio ejecutando:
    git clone [AQUI_LA_URL_DEL_REPOSITORIO]
    cd LaComanda-SaaS-Azul

4 ¡Levantar el Proyecto! 🚀

Con Docker abierto en segundo plano y tu terminal ubicada dentro de la carpeta del proyecto, ejecuta el comando mágico:

docker compose up --build

¿Qué está pasando?

La primera vez que ejecutes esto, Docker descargará Internet entero (es broma, pero descargará MySQL, Node.js y compilará el frontend y el backend). Puede tardar varios minutos. Sé paciente.

help Solución de Problemas Comunes

Error: "Docker daemon is not running"

Asegúrate de haber abierto la aplicación "Docker Desktop" desde el menú de inicio de Windows y espera a que el ícono esté en verde antes de correr comandos.

Error: Puerto 3306 (o 3000/5173) está en uso

Significa que ya tienes XAMPP, Laragon u otro MySQL corriendo en tu PC. Debes apagar esos servicios locales para que Docker pueda usar esos puertos.

Quiero detener el proyecto, ¿qué hago?

En la terminal donde corriste el docker compose, simplemente presiona Ctrl + C. Para asegurarte de apagar todo correctamente, puedes correr docker compose down.
